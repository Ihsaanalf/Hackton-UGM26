# ReValue UI Prototype

Prototype frontend untuk alur:
Home → Scan Sampah → Hasil Identifikasi AI → Collective.

## Jalankan
```bash
npm install
npm run dev
```

Buka URL Vite yang muncul di terminal.

## Catatan
Data AI, harga, berat, dan collective masih dummy untuk prototype. Tahap berikutnya dapat mengganti data dummy dengan backend/API dan model klasifikasi material.
